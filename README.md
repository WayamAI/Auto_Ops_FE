# Wayam AI Auto Ops 🚀
### Autonomous Operations for ServiceNow Infrastructure

Wayam AI Auto Ops is an autonomous operations platform for enterprises running ServiceNow
infrastructure. Specialized AI agents monitor MID Servers, containers, networks, databases,
and ServiceNow authentication, then diagnose and safely remediate incidents end to end: root
cause analysis, a governed remediation plan, execution, and post fix validation.

---

## 🛠 Core Value Propositions

*   **Autonomous Remediation Pipeline**: End to end automation from incident detection to validation.
    *   **RCA**: Intelligent root cause identification with confidence scoring.
    *   **Planning**: AI generated remediation plans with risk assessment.
    *   **Execution**: Safe execution of fixes via a secure tool registry.
    *   **Validation**: Automated post remediation checks to ensure service health.
*   **MID Server Specialist**: Built in intelligence for the most common and complex ServiceNow infrastructure issues:
    *   JVM heap and memory exhaustion.
    *   ECC queue thread pool optimization.
    *   Zombie upgrade loops and stale binary cleanup.
    *   Credential rotation (including HashiCorp Vault integration).
*   **Human in the Loop Governance**: Ensure safety with granular approval workflows, blast radius analysis, and mandatory manual intervention for high risk changes.
*   **Enterprise ROI Tracking**: Live ticker showing value generated by auto resolving incidents compared to manual resolution costs.

## 🏗 Key Modules

### 🕹 Control Tower
The central cockpit for operational visibility.
- **Live Activity Feed**: Live stream of agent actions and incident transitions.
- **Metrics Dashboard**: ROI tracking, routing accuracy, and success rates.

### ⚡ Actions Module
The operational heart for monitoring and managing active remediations.
- **Execution Progress**: Granular tracking of the 5 stage pipeline (Alert → RCA → Plan → Execute → Validate).
- **Log Streaming**: Deep visibility into agent reasoning and tool executions as they happen.
- **Governance Integration**: Direct links to Approval Queue for pending review actions.
- **Contextual Insight**: Integrated blast radius maps and ServiceNow record linking for every action.
- **Approval Quick Actions**: Approve, modify, or reject remediation plans directly from the dashboard.

### 🏥 Health Monitor
Deep visibility into the infrastructure layer.
- **Node Level Health**: Monitor heartbeat, JVM heap, and ECC queue status for every MID Server.
- **Credential Watch**: Automated tracking and rotation of service account credentials.
- **Health Timelines**: 24 hour visual history of errors and performance metrics.

### 🧠 Knowledge Engine & Tool Registry
The brain and the hands of the platform.
- **Pattern Mining**: Learning from historical incidents to suggest faster fixes.
- **Tool Catalog**: Secure, audited catalog of automation tools (SSH, Kubernetes, cloud APIs, ServiceNow probes).

### 👮 Approval Queue
Comprehensive governance for high stakes operations.
- **Blast Radius Analysis**: Visual impact mapping for proposed fixes.
- **Rollback Plans**: Every automated action includes a predefined rollback strategy.
- **Collaborative Review**: Detailed reasoning and historical context for every approval request.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/) or [Bun](https://bun.sh/)

### Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Copy `.env.example` to `.env` (optional — the app runs fully in demo mode with zero configuration):
   ```bash
   cp .env.example .env
   ```

### Demo Mode

The app defaults to **demo mode** (`VITE_DEMO_MODE=true` or unset), which runs entirely client
side with no backend required:

- **Login** accepts any syntactically valid email address and any non empty password.
- **Dashboards** are populated from a realistic in memory dataset (`src/api/demoData.ts`)
  covering agents, incidents, MID servers, approvals, tools, and notifications.
- Interactive actions (approve/reject, add tool, mark notification read, create access
  profile) mutate that in memory store so the demo feels alive across a session.

To connect a real backend instead, set `VITE_DEMO_MODE=false` and `VITE_API_BASE_URL` to your
API's URL — see `API_REQUIREMENTS.md` for the full endpoint contract. The app then uses the
original email → OTP → verify authentication flow and live API calls throughout.

### Development
Start the local development server:
```bash
npm run dev
```

## 🌍 Deployment

The project is optimized for deployment on **Vercel**.

**Note**: To handle client side routing correctly on Vercel (preventing 404s on page refresh), ensure the `vercel.json` file is present in the root with the following configuration:

```json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```
